# PhasmoGuide

A desktop companion app for [Phasmophobia](https://kineticgames.co.uk/phasmophobia), built with Electron. It's meant to sit next to the game while you play — narrow down which ghost you're dealing with, look up a map's layout before you walk in, keep track of hunt timers, and ask a chatty in-game "ghost expert" a quick question without alt-tabbing to a wiki.

This is a personal fan project. It isn't affiliated with or endorsed by Kinetic Games.

## What it does

**Ghosts** — Toggle evidence on/off (with difficulty-aware evidence caps) to narrow the ghost list down live. Pick a ghost to see its full profile: speed (with a per-state breakdown for ghosts whose speed changes, and a 🔊 button that plays back its actual footstep cadence), hunt sanity threshold, strengths/weaknesses, and expandable notes for anything with a real in-game quirk.

**Maps** — All of the game's maps, grouped by size (Small/Medium/Large). Each one has its Rooms/Sanity/Temperature floor-plan diagrams, a hiding-spots breakdown (which sanctioned spots exist, how many stay open at each difficulty, and the multiplayer bonus), cursed possession spawn locations with photos, and layout tips pulled straight from the wiki.

**Timers** — The four timers you actually need mid-hunt (Incense window, Hunt Cooldown, Hunt Duration, Paranormal Sound window) always present and un-removable, plus the ability to add your own custom countdown timers.

**Footsteps** — Tap along with footstep sounds you hear in-game and it estimates the ghost's speed, then cross-references that against every ghost's known speed range to shortlist candidates.

**Strategies** — A condensed, per-ghost cheat sheet for what to listen/look for to identify it quickly.

**Themes** — A dark violet-and-ecto-green theme by default, and the app automatically switches to a seasonal look around real-world holidays: a firefly-lit spring theme near Easter, a blood-moon Halloween with drifting fog and bats, and a spooky (not cheerful) Christmas with falling snow.

## Jerry — powered by Claude

The Jerry tab is a chat window where you can ask questions in plain English ("what's Mare's hunt threshold?", "where's the cursed possession on Edgefield?") and get an answer back in character, like you're messaging a friend who's really into the game.

Under the hood, Jerry is [Claude](https://www.anthropic.com/claude) (Haiku 4.5) called through the Anthropic API. He's deliberately kept on a short leash: the only facts he's allowed to use are the same ghost and strategy data this app already scrapes from the wiki, fed to him as grounding context on every request. If something isn't in that data, he's instructed to say he's not sure rather than make it up.

Jerry needs your own Anthropic API key to work (get one at [console.anthropic.com](https://console.anthropic.com)). Paste it into the key field on the Jerry tab — it's encrypted with Electron's OS-level `safeStorage` and saved locally on your machine; it's never bundled with the app or sent anywhere except directly to Anthropic when you send a message.

## Getting started

```bash
npm install
npm start
```

To refresh the ghost or map data from the wiki (e.g. after a game update):

```bash
npm run scrape         # ghosts
npm run scrape:maps    # maps
```

To build a distributable Windows installer:

```bash
npm run build
```

## How the data works

`app/data/ghosts-data.js` and `app/data/maps-data.js` aren't hand-written — they're generated by `scripts/scrape-ghosts.js` and `scripts/scrape-maps.js`, which pull structured data (evidence, speeds, sanity thresholds, map layouts, hiding spots, cursed possession locations, and so on) from the [Phasmophobia Fandom wiki](https://phasmophobia.fandom.com/) and normalize it into the shape the app reads. A few values that don't come from a clean structured field on the wiki (like ghosts with multi-state speeds) are hand-verified overrides in the scraper itself, called out in comments where that happens.

## Built with Claude Code

This was my first project building something with Claude Code, and it turned into a genuine back-and-forth rather than me just handing off tasks. It started small — timers, a ghost reference list — and grew one conversation at a time into everything above: a full dark theme (with a real bug fix or two caught along the way, like a broken CSS selector that was silently killing half the Christmas snow), a footstep-tempo audio tool, an entire Maps tab built by figuring out the wiki's page structure together, seasonal auto-switching themes, and even a custom-drawn app icon. A good chunk of this README is written the same way — describing what actually got built, together, rather than a spec written up front.
